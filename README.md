## Installation status

These are the editable sources. The public distribution (`distributions/` and root `cytv-themes.json`) must be added after committing the sources. Target: Home 1.20.5, ribbon-layout-v1. Hardware acceptance is pending. No local receiver or helper changes are required for the published-theme installation route.

Theme subdirectories include their own MIT license and artwork credits; the repository root license is not replaced by this upload.
